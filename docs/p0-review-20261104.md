## Existing rules to preserve

- Arithmetic mean of accepted independent channel samples; no depreciation coefficient.
- Used service has no Car.ir dependency.
- Tehran publication day and the existing late-arrival/finalization window.
- Current price cannot be overwritten by an older price day.
- Raw-message uniqueness `(ChannelId, ExternalMessageId)` and independent zero part uniqueness.
- Zero crawler reads the market column, never the factory column.
- Zero parts, validation, reference comparison and storage remain independent of used extraction.
- Historical/raw production data must not be deleted. No merge or deploy is authorized by this task.

## Additional confirmed fixes during implementation

- CarService metadata forms started parallel EF queries on one scoped context; queries now execute sequentially.
- Legacy published derivatives with matching immutable raw bodies are versioned and audited before year/trim regrouping. Manual matches, deleted rows and raw-body conflicts are protected; finalized history is retained.
- Manual price recalculation is now a durable backend request returning 202, including across restarts.
- Source alias reconciliation is transactional and stops on conflicting historical metadata rather than guessing.
- Job counters snapshot each completed run; old runs are explicitly marked as lacking recorded counters.
